# 内部结构格式 + 接口文档

> 版本 v0.1 | 阶段 0 交付物 | 负责人 A 起草，全员遵守
> 本文件是全组唯一的"通用语言"定义。任何模块间的数据传递必须经过这里定义的格式，禁止私自发明新格式。修改本文件需在组内通知。

---

## 1. 全局约定

| 项目 | 约定 |
|---|---|
| 长度单位 | 埃（Å） |
| 坐标系 | 右手系，列向量坐标，矩阵左乘 |
| 晶格矢量 | 3×3 矩阵 `lattice_vectors`，**行向量**为 a1、a2、a3（卡氏坐标，Å） |
| 分数坐标 → 卡氏坐标 | `cart = frac @ lattice_vectors`（frac 为 N×3） |
| 方向指数 | 三指数 `[u v w]`，Python 中为 `tuple(int, int, int)`；HCP 四指数输入在 GUI 层转换为三指数后进入内核（内核永远不处理四指数） |
| 晶面指数 | 三指数 `(h k l)` |
| 旋转矩阵 | 3×3 正交矩阵 `R`，行向量为新坐标系 x'、y'、z' 在旧坐标系中的表达；旋转：`cart_new = cart_old @ R.T`。约定 **z' 恒为观察方向** |

## 2. 核心数据结构：`Crystal`

所有模块（单晶/双晶/孪晶/IO/渲染）之间传递的唯一结构对象，定义于 `core/structure.py`：

```python
@dataclass
class Crystal:
    name: str                     # 结构名称，如 "FCC Cu"
    lattice_vectors: np.ndarray   # (3,3) float64，行向量 a1,a2,a3，单位 Å
    basis: np.ndarray             # (N,3) float64，单胞内原子分数坐标
    species: list[str]            # 长度 N，每个基元原子的元素符号，如 ["Cu","Cu","Cu","Cu"]
    meta: dict                    # 扩展信息（见 §2.1），无则为 {}
```

### 2.1 `meta` 保留键（各模块按需写入）

| 键 | 写入者 | 内容 |
|---|---|---|
| `lattice_type` | IO / 工厂函数 | `"FCC"` / `"BCC"` / `"HCP"` / ... |
| `lattice_params` | IO / 工厂函数 | `{"a": 3.615}` 或 `{"a": 2.492, "c": 4.066}` |
| `source` | IO | 来源（文件路径 / 内置库 ID） |
| `grain_id` | 双晶/孪晶模块 | 晶粒编号，0/1，用于界面与配色区分 |
| `transform` | 双晶/孪晶模块 | 该晶粒相对参考取向的 3×3 旋转矩阵 |
| `interface_plane` | 双晶/孪晶模块 | 界面晶面 (h k l) |

### 2.2 合法性子约定

- `basis` 的每一行 ∈ [0, 1)³（超胞展开由 `Crystal.supercell()` 负责，调用方不得自行平铺）
- `len(species) == basis.shape[0]`，构造时校验，不满足直接抛 `ValueError`

数据库 JSON 分两段：`lattice_types`（结构类型 → 基元说明）+ `materials`（每条 = lattice_type / elements / a / c / note）。
坐标全部用分数坐标生成器按类型展开，**库中只存晶格常数**。当前覆盖 9 种类型 39 种材料：
sc(Po)、fcc(9)、bcc(8)、hcp(7)、diamond(Si/Ge/C/α-Sn)、nacl(NaCl/MgO/NiO)、cscl(CsCl/NiAl)、zincblende(ZnS/GaAs/InSb)、l12(Cu3Au/Ni3Al)。
新增材料只需在 JSON 加一行；新增结构类型需在 `crystio/database.py` 的 `_gen()` 加一个分支。

## 4. 数据流

```
用户输入(uvw / OR / 孪生系)
   → GUI 校验、转三指数
   → load_structure / 工厂函数  → Crystal
   → 取向引擎(rotation_from_uvw / or_to_rotation / twin_transform) → R
   → （双晶/孪晶：build_bicrystal / build_twin 合成新 Crystal）
   → project() → (x, y, z, species)
   → render() → PNG / GUI 画布
```
