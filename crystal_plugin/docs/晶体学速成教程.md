## 第 0 章　先建立一个总体图景

我们要干的事，本质上就三步：

```
一个晶体（一堆原子的坐标）
   → ① 旋转它（转到你要看的方向）
   → ② 从那个方向"拍照"（正交投影到平面）
   → ③ 把照片画出来
```

**几乎所有晶体学知识，都是为了让第 ① 步的"旋转"算得对。** 双晶和孪晶也不过是"旋转两份晶体再拼起来"。所以本教程的主线就是：**怎么描述晶体的方向，怎么对晶体做旋转。**

## 第 1 章　晶胞、晶格常数与分数坐标

### 1.1 晶体 = 花砖铺地

晶体是周期性结构：拿一块最小的"花砖"（**晶胞**，unit cell），沿三个方向无限平铺，就得到整块晶体。

- 描述花砖需要 6 个量：三条棱长 **a, b, c**（**晶格常数**，单位 Å，1 Å = 0.1 nm）和三个夹角 **α, β, γ**
- 花砖的三个棱矢量记作 **a₁, a₂, a₃**（**晶格矢量**）

常见金属只有三种对称性，记住这张表（这也是我们 `structure.py` 里的三个工厂函数）：

| 结构 | 中文 | 单胞内原子位置（分数坐标） | 例子 | 晶格常数(Å) |
|---|---|---|---|---|
| FCC | 面心立方 | 8个顶点 + 6个面心 | Al 4.05, Cu 3.615, γ-Fe 3.59 |
| BCC | 体心立方 | 8个顶点 + 1个体心 | α-Fe 2.866, W 3.165 |
| HCP | 密排六方 | 见 §1.4 | Mg a=3.209 c=5.211, Ti a=2.951 c=4.686 |

FCC/BCC 立方晶系只需要 1 个参数 a（三个边等长且互相垂直）；HCP 需要 2 个参数 a 和 c。

### 1.2 分数坐标 —— 整个项目最重要的一个表示

描述晶胞内原子位置，**不用 Å，而用"占三条棱的几分之几"**，这叫**分数坐标**：

```
原子位置 = f₁·a₁ + f₂·a₂ + f₃·a₃，  f = (f₁, f₂, f₃) ∈ [0,1)³
```

例：FCC 面心原子的分数坐标是 (0.5, 0.5, 0) —— 在 a₁ 方向走一半、a₂ 方向走一半、a₃ 方向不动。

**为什么用分数坐标？** 因为平移对称性在分数坐标下就是简单的"加 1"：原子 (0.5,0.5,0) 在隔壁晶胞的对应原子就是 (1.5,0.5,0)。超胞展开就是遍历加整数：

```python
# 项目 core/structure.py 中 Crystal.supercell() 干的事：
for i in range(nx):
    for j in range(ny):
        for k in range(nz):
            新原子分数坐标 = 原分数坐标 + (i, j, k)
```

分数坐标与卡氏坐标（Å）的换算：**`cart = frac @ lattice_vectors`**（frac 是行向量，lattice_vectors 的行是 a₁,a₂,a₃）。这一行代码在项目中出现了无数次，务必理解。

### 1.3 单胞 vs 原胞 vs 超胞

- **原胞**：只含 1 个原点的最小重复单元（数学上最美，但难看）
- **惯用单胞**：体现对称性的单胞。FCC 惯用胞含 4 个原子（8顶点×1/8 + 6面心×1/2 = 4），BCC 含 2 个，HCP 含 2 个（惯用六棱柱含 6 个，但我们用菱柱单胞）
- **超胞**：把单胞沿三个方向复制 n×m×k 倍。投影时为了画面饱满，我们取 3~4 倍超胞

### 1.4 HCP 的单胞（需要单独记）

HCP 惯用菱柱单胞的三条晶格矢量（卡氏坐标）：

```
a₁ = (a, 0, 0)
a₂ = (-a/2, a√3/2, 0)      ← 与 a₁ 夹角 120°
a₃ = (0, 0, c)
```

两个原子的分数坐标：(1/3, 2/3, 1/4) 和 (2/3, 1/3, 3/4)。

**自测 1**：用上面公式验证 Mg（a=3.209, c=5.211）的两个原子卡氏坐标。
<details><summary>答案</summary>
(1/3,2/3,1/4) → 0.333×a₁ + 0.667×a₂ + 0.25×a₃
= (0.333×3.209 − 0.667×1.6045, 0.667×2.779, 0.25×5.211) = (0.000, 1.853, 1.303) Å。
另一个同理得 (1.6045, 0.926, 3.908) Å。</details>

**理想 HCP 的 c/a = √(8/3) ≈ 1.633**。Mg 的 c/a = 1.624，接近理想；Zn 的 c/a = 1.856，明显偏高。

## 第 2 章　晶向指数 [uvw] 与晶面指数 (hkl) —— 项目的"输入语言"

这是用户输入的方式，也是题目中"任意方向 [uvw]"的含义，**必须滚瓜烂熟**。

### 2.1 晶向指数 [uvw]

一条晶向 = 一个矢量 = u·a₁ + v·a₂ + w·a₃。取 u,v,w 为**最小整数比**，写在方括号里：**[uvw]**。

- [100]：沿 a₁ 轴方向
- [110]：立方晶胞的面对角线方向
- [111]：立方晶胞的体对角线方向
- 负分量写上划线，如 [1̄10]（程序里写 (-1, 1, 0)）

**注意陷阱**：在立方晶系里 [uvw] 直接就是卡氏方向 (u,v,w)；但在 HCP 等非立方晶系里，[uvw] 是**分数系数**，真实方向要乘晶格矢量矩阵（`uvw @ lattice_vectors`）。这就是 `orientation.py` 里 `_frac_dir_to_cart()` 存在的意义。

一族对称等价的晶向用尖括号 **⟨uvw⟩** 表示，如立方晶系 ⟨100⟩ = [100],[010],[001],[1̄00],[01̄0],[001̄] 共 6 个。

### 2.2 晶面指数 (hkl)（米勒指数）

一个晶面（原子排列成的平面）用**截距倒数**定义：

1. 找到晶面在三条晶轴上的截距（以 a,b,c 为单位）：比如 (1, 2, ∞)
2. 取倒数：(1, 1/2, 0)
3. 化为最小整数：**(2, 1, 0)**，写在圆括号里

- 截距为 ∞（晶面与该轴平行）→ 倒数为 0
- 立方晶系三个最重要的面：(100) 立方体表面、(110) 对角竖切面、(111) 体对角垂直面（**FCC 的密排面**）
- 一族对称等价晶面用花括号 **{hkl}**

**立方晶系的巧合（要记住，但别滥用）**：(hkl) 面的法线方向恰好就是 [hkl] 方向。**仅在立方晶系成立**！HCP 中不成立（见第 3 章）。

### 2.3 晶面间距 d(hkl)

相邻两个平行晶面间的距离，XRD 和投影层间距都要用它：

- 立方：`d = a / √(h²+k²+l²)`
- 六方：`1/d² = (4/3)(h²+hk+k²)/a² + l²/c²`

例：FCC Cu (111) 面间距 = 3.615/√3 = 2.087 Å —— 这正是我们 Cu[111] 投影图的层间距（验证报告里的"深度层数"就是按它分层）。

### 2.4 HCP 的四指数 [uvtw] 与 (hkil)

HCP 对称性是六重的，三个基矢里 a₁、a₂ 等价，为了对称美，引入冗余的第三个面内轴 a₃' = −(a₁+a₂)，于是出现四指数：

- 晶面四指数 (hkil)：约束 **i = −(h+k)**，如 (0001)、(101̄0)、(112̄0)
- 晶向四指数 [uvtw]：约束 **t = −(u+v)**

**三指数 ↔ 四指数换算公式（必背）**：

```
晶向 [U V W]（三指数）→ [u v t w]（四指数）：
    u = (2U − V)/3,  v = (2V − U)/3,  t = −(u+v),  w = W
    然后约成最小整数
四指数 → 三指数：
    U = u − t,  V = v − t,  W = w

晶面 (h k l) → (h k i l)：i = −(h+k)，其余照抄（晶面换算是平凡的）
```

例：Mg 的重要晶向 [112̄3]（四指数）→ U=1−1=0? 不对，算一下：u=1,v=1,t=−2 → U=1−(−2)=3, V=1−(−2)=3, W=3 → 三指数 [1 1 1]（除以3）。方向不同记号不同，注意别混。

**项目约定（接口文档 §1）**：GUI 层接受四指数输入，**转成三指数后才进入内核**，内核永远不处理四指数。这是为了内核代码干净。

## 第 3 章　正点阵、倒易点阵与晶带定律

这一章回答一个关键问题：**"面法线"在非立方晶系里到底是什么方向？**

### 3.1 倒易点阵 —— 15 分钟版

对正点阵基矢 a₁,a₂,a₃，定义**倒易基矢** b₁,b₂,b₃：

```
b₁ = 2π (a₂×a₃)/V,  b₂ = 2π (a₃×a₁)/V,  b₃ = 2π (a₁×a₂)/V,   V = a₁·(a₂×a₃) 是单胞体积
```

性质：**aᵢ·bⱼ = 2πδᵢⱼ**（i=j 时为 2π，否则为 0）。

**核心结论（唯一需要记住的）**：

> 晶面 (hkl) 的法线方向 = 倒易矢量 **G = h·b₁ + k·b₂ + l·b₃** 的方向
> 晶面间距 d(hkl) = 2π/|G|

立方晶系中 bᵢ ∥ aᵢ，所以"面法线 = [hkl]"；HCP 中 a₃ ∥ b₃，所以基面 (0001) 法线仍是 [0001]，但 (101̄0) 法线就**不是** [101̄0] 了。

### 3.2 度规张量 G —— 程序里的实际做法

代码里不显式算倒易基矢，而是用**度规张量** `G = L @ L.T`（L 是晶格矢量矩阵）。它让你能在**分数坐标下直接算角度和长度**：

```
两个分数方向 d₁, d₂ 的点积（卡氏意义）= d₁ · G · d₂ᵀ
```

判断 [uvw] ⊥ [u'v'w']：`uvw @ G @ [u'v'w']ᵀ == 0`。`orientation.py` 里检查"面内晶向与观察方向垂直"用的就是这个，立方晶系时 G = a²I 退化为普通点积。

### 3.3 晶带定律（Weiss zone law）

**晶带**：一系列晶面，它们的法线都垂直于同一个方向 [uvw]（叫**晶带轴**），这些面互相交线都平行于 [uvw]。

**晶带定律**：晶面 (hkl) 属于晶带 [uvw] ⟺ **hu + kv + lw = 0**（点积为零）

物理意义：(hkl) 面的法线 ⊥ [uvw] ⟺ [uvw] 躺在 (hkl) 面内。

**为什么这对项目至关重要**：用户输入观察方向 [uvw] 后，程序要选一个"面内参考晶向"来定画面的 x 轴。这个参考晶向必须是**真实躺在垂直于 uvw 的平面里的方向**。在立方晶系里就是找与 uvw 点积为零的晶向 —— 正是晶带定律的形式。`orientation.py` 的 `_pick_in_plane_index()` 里三个候选 (v,−u,0)、(w,0,−u)、(0,w,−v) 就是手动解 hu+kv+lw=0 得到的。

**自测 2**：观察方向 [110]，下列哪些是合法的面内晶向？[001]、[111]、[1̄10]。
<details><summary>答案</summary>用 hu+kv+lw=0（此处 hkl 取方向，uvw=[110]）：
[001]: 1×0+1×0+0×1=0 ✓；[111]: 1+1+0=2 ✗；[1̄10]: −1+1+0=0 ✓。
所以 [001] 和 [1̄10] 都合法。</details>

## 第 4 章　取向的数学描述 —— 项目的发动机

"取向"= 晶体相对于外部坐标系转了怎样的角度。有四种等价描述，项目里主用第一种。

### 4.1 旋转矩阵（取向矩阵）—— 项目主用

3×3 正交矩阵 R，满足 `R·Rᵀ = I` 且 `det(R) = +1`（+1 表示纯旋转，−1 表示含镜像/反演）。

**项目约定（接口文档 §1）**：

- R 的**行向量**是新坐标轴 x′、y′、z′ 在旧坐标系中的表达
- **z′ 恒为观察方向**（这是整个设计的核心约定！）
- 旋转一个原子坐标：`cart_new = cart_old @ R.T`

**任意观察方向的 R 怎么构造**（`orientation.py` 的算法，三步）：

```
1. ez = 归一化([uvw] 的卡氏方向)          # z' 对准观察方向
2. ex = 归一化(面内参考晶向的卡氏方向)     # 必须 ⊥ uvw（晶带定律）
3. ey = ez × ex  （叉乘，自动 ⊥ 前两个）   # 再正交化一次消除数值误差
R = [ex; ey; ez]（按行堆叠）
```

**自测 3**：手算 [001] 观察、面内 [100] 时的 R。
<details><summary>答案</summary>ez=(0,0,1)，ex=(1,0,0)，ey=ez×ex=(0,1,0)，R=单位阵。理所当然：沿 z 看就是原样。</details>

**自测 4**：手算 [110] 观察、面内 [001] 时的 R。
<details><summary>答案</summary>ez=(1,1,0)/√2，ex=(0,0,1)，ey=ez×ex=(1,−1,0)/√2。
R = [[0,0,1],[0.707,−0.707,0],[0.707,0.707,0]]。</details>

### 4.2 其他三种描述（了解即可，答辩可能被问）

| 描述 | 内容 | 参数个数 | 备注 |
|---|---|---|---|
| 旋转矩阵 R | 3×3 正交矩阵 | 9（约束后自由度3） | 计算最方便，项目主用 |
| 欧拉角 (φ₁,Φ,φ₂) | 绕 z→新x→新z′ 连转三次 | 3 | EBSD 领域标准（Bunge 约定），评审可能提 |
| 轴角对 (n, θ) | 绕轴 n 转 θ 角 | 4（自由度3） | 物理最直观，孪晶=绕法线转180° |
| 四元数 q | (q₀,q₁,q₂,q₃)，|q|=1 | 4（自由度3） | 插值平滑、无奇点，orix 库内部用它 |

四种之间可以互相换算（公式可查，orix 库全都有）。自由度都是 3 —— 三维旋转本质只有 3 个独立参数。

**轴角对→旋转矩阵**用 Rodrigues 公式（孪晶模块会用到，绕孪晶面法线转 180°）：

```
R = I·cosθ + (1−cosθ)(n⊗n) + sinθ·[n]×     （[n]× 是 n 的反对称叉乘矩阵）
```

### 4.3 对称性与等价取向

立方晶系有 24 个旋转对称操作（点群 m3̄m）。所以"同一个观察效果"有 24 种旋转矩阵描述。这引出 OR 变体数量的概念（第 5 章）。

## 第 5 章　经典取向关系（OR）—— 双晶模块的输入

### 5.1 什么是取向关系

固态相变（如钢中 γ-Fe 奥氏体 → α-Fe 铁素体/马氏体）时，新相和母相的晶体取向**不是随机的**，而是保持确定的平行关系：

> OR = "某相的某晶面 ∥ 另一相的某晶面" + "某相的某晶向 ∥ 另一相的某晶向"

记法示例（K-S 关系）：**(111)γ ∥ (011)α，[101̄]γ ∥ [11̄1̄]α**

### 5.2 五个必知经典 OR

| OR | 相组合 | 平行晶面 | 平行晶向 | 出现场合 | 变体数 |
|---|---|---|---|---|---|
| **K-S**（Kurdjumov–Sachs） | FCC↔BCC | (111)γ∥(011)α | [101̄]γ∥[11̄1̄]α | 钢中马氏体 | 24 |
| **N-W**（Nishiyama–Wassermann） | FCC↔BCC | (111)γ∥(011)α | [112̄]γ∥[01̄1]α | 钢、铜合金 | 12 |
| **Pitsch** | FCC↔BCC | (100)γ∥(110)α 类 | 较复杂 | 铁素体析出 | — |
| **Burgers** | BCC↔HCP | (110)BCC∥(0001)HCP | [111̄]BCC∥[112̄0]HCP | Ti、Zr 合金 β→α | 12 |
| **G-T**（Greninger–Troiano） | FCC↔BCC | 接近 K-S 但有微小偏差 | 无理指数 | 马氏体惯习面研究 | — |

记忆要点：K-S 与 N-W 晶面相同、晶向不同（面内转了约 5.26°）；Burgers 是 BCC↔HCP 版的 K-S。

**变体数怎么来的**：OR 本身固定了两相的相对取向，但母相的 24 个对称操作会产生 24 个"看起来不同但物理等价"的新相取向，扣掉重复后：K-S 有 24 个变体，N-W 有 12 个（因为 [112̄] 型方向对称性更低）。

### 5.3 OR → 旋转矩阵（C 同学的核心算法）

给两相各自的晶格矢量 L₁、L₂，以及 OR 的 (hkl)₁∥(hkl)₂、[uvw]₁∥[uvw]₂：

```
1. 在相1中构造正交标架：e1 = [uvw]₁ 方向；e2 = (hkl)₁ 面内 ⊥ e1 的方向；e3 = e1×e2
2. 在相2中同样构造标架 f1, f2, f3
3. R = F · Eᵀ   （把相1的标架转到相2的标架）
```

注意非立方晶系中"面法线"要用倒易点阵算（第 3 章），这是最容易出错的地方。

### 5.4 双晶界面的两种构建思路

1. **查表法（保底方案）**：内置几个预计算好的 OR 矩阵，直接把两份单胞按 R 相对旋转、沿界面法线拼接。实现简单，答辩够用。
2. **CSL 法（进阶）**：见第 7 章。

## 第 6 章　孪生要素 —— 孪晶模块的输入

### 6.1 什么是孪晶

孪晶 = 同种晶体的两部分，沿一个公共晶面（**孪晶面 K₁**）呈**镜像对称**（或绕面法线旋转 180°，二者对孪晶等价）。塑性变形时发生"变形孪生"：晶体的一部分像推卡片一样整体切变过去。

### 6.2 四个孪生要素 + 切变量（必须会画这张图）

```
            η₂
     K₂  ───────────  （第二个不畸变面，切变后转到新位置）
      ╲
       ╲   切变方向 s
        ╲ ↓
   K₁ ──●─────────────→ η₁   （孪晶面：不转动不畸变的面）
        ↑ 孪晶切变使上半部分原子沿 η₁ 方向平移，位移量随离 K₁ 距离线性增加
```

- **K₁**：孪晶面（切变平面），唯一不转动、不畸变的面
- **η₁**：孪生方向（切变方向），躺在 K₁ 面内
- **K₂**：第二个不畸变面（切变前与切变后它都不变，只是转了角度）
- **η₂**：K₂ 与切变平面的交线方向
- **切变量 s**：单位高度处的平移位移，s 越大畸变越厉害

### 6.3 三种晶系的经典孪生系（数据库要录入的内容）

| 晶系 | K₁ | η₁ | K₂ | η₂ | s | 备注 |
|---|---|---|---|---|---|---|
| FCC | {111} | ⟨112̄⟩ | {111} | ⟨112⟩ | 1/√2 ≈ 0.707 | Cu、Al（Al 层错能高少见）|
| BCC | {112} | ⟨11̄1⟩ | {112̄} | ⟨111⟩ | 1/√2 | α-Fe、W |
| HCP | {101̄2} | ⟨101̄1̄⟩ | {101̄2̄} | ⟨101̄1⟩ | 依 c/a 变 | **拉伸孪晶**，Mg、Ti、Zn 最常见 |
| HCP | {112̄2} | ⟨112̄3̄⟩ | — | — | — | 压缩孪晶，c/a 低时出现 |

经验规律：c/a > √3（如 Zn 1.856）时 {101̄2} 是压缩孪晶；c/a < √3（如 Mg 1.624）时是拉伸孪晶。

### 6.4 孪晶怎么在程序里生成（D 同学的算法）

两种等价做法：

1. **镜像法（Atomsk 的做法，推荐）**：把晶体对 K₁ 面做镜像反射，然后平移使界面原子对上，拼接。镜像矩阵：`M = I − 2·n·nᵀ`（n 是 K₁ 单位法向量）。注意镜像是 det=−1 的变换。
2. **旋转法**：绕 K₁ 法线旋转 180°（对中心对称的晶面与镜像等价），用 Rodrigues 公式 θ=π。

拼接后界面附近要**删除重叠原子**（两个原子距离 < 0.5×最近邻距离时删一个）——这是孪晶/双晶模块最容易出 bug 的地方。

**自测 5**：FCC 的 K₁=(111)，写出其镜像矩阵（a 取 1）。
<details><summary>答案</summary>n=(1,1,1)/√3。M = I − 2nnᵀ =
[[1/3, −2/3, −2/3],[−2/3, 1/3, −2/3],[−2/3, −2/3, 1/3]]。验证 det(M)=−1。</details>

## 第 7 章　CSL 与 DSC —— 双晶界面的理论（进阶，了解即可）

### 7.1 CSL（重位点阵，Coincidence Site Lattice）

把同种晶体的两份绕某轴转某个角度，会发现**有一部分阵点恰好重合**。这些重合点构成的点阵叫 CSL。

- **Σ 值** = CSL 单胞体积 / 原晶体单胞体积 = "每 Σ 个阵点中有 1 个重合"
- Σ 越小，界面匹配越好、界面能通常越低
- 经典例子：绕 [001] 转 36.87° 得 **Σ5**；绕 [111] 转 60° 得 **Σ3 —— 这就是 FCC 的退火孪晶界！**（孪晶是特殊的低 Σ 晶界）

所以孪晶和双晶在数学上是统一的：都是"两份晶体 + 一个相对取向 + 一个界面"。我们项目的 `build_bicrystal` 和 `build_twin` 共用一套拼接代码就是这个原因。

### 7.2 DSC 点阵

两份晶体的**所有**平移矢量（保持 CSL 不变的位移）构成的点阵。晶界台阶、晶界位错的柏氏矢量都是 DSC 矢量。答辩阶段只需知道名词和"它描述晶界允许的缺陷"。

### 7.3 项目的取舍

CSL 自动搜索（任意两相、任意取向找低 Σ 界面）是 C 同学的进阶目标，参考 `interface_master` 的做法。**保底方案是查表法**（§5.4），计划里已留好退路。

## 第 8 章　正交投影与深度分层 —— 渲染的原理

### 8.1 正交投影

旋转之后，观察方向是 z′ 轴，那么"照片"就是：**扔掉 z′ 坐标，只画 (x′, y′)**。这就是正交投影（平行光拍照，无透视变形）——电镜衍射花样、极射投影的物理本质都是某种投影。

```python
# core/projector.py 的核心三行：
cart -= cart.mean(axis=0)   # 居中：让画面以原点为中心
rot = cart @ R.T            # 旋转到新坐标系
x, y, z_depth = rot[:,0], rot[:,1], rot[:,2]   # x',y' 画图，z' 记录深度
```

### 8.2 为什么投影图能"看出"晶体结构

不同观察方向下，原子投影的对称性完全不同：

- FCC 沿 [110]：矩形网格状（面心原子投影在矩形中心）
- FCC 沿 [111]：六重对称的密排图案
- BCC 沿 [111]：六重对称但层间距不同
- HCP 沿 [0001]：基面 AB 两层原子交替

这正是演示的卖点：**同一个晶体，转个方向，"指纹"完全不同**——就像材料人看 SAED 衍射花样判断晶带轴一样。

### 8.3 深度分层

沿观察方向，原子落在一系列平行的等距平面上（层间距 = d(hkl) 或其分数倍）。渲染时按 z′ 四舍五入到 0.5 Å 分层，**远的层画暗、先画；近的层画亮、后画**，就有了立体感。这就是 `render()` 里 `layer_shade` 的逻辑。
